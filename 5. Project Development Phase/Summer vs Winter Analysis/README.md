# Summer vs Winter Games Analysis: Seasonal Comparison & Disparities

**Project:** Global Olympic Sports Performance Analysis  
**Author:** Md. Firdous Alam  
**Live Dashboard:** [Tableau Public Profile](https://public.tableau.com/app/profile/md.firdous.alam/viz/GlobalOlympicSportsPerformanceAnalysis_17933559199720/Dashboard3)  

## Overview
Comparative evaluation of Summer and Winter Games, highlighting geographic concentration, athlete scale, and medal distributions.

## Key Analytical Highlights
- Summer Games: 29 editions, 15,683 medals, global participation across 200+ nations
- Winter Games: 22 editions, 3,222 medals, heavy concentration among cold-climate nations
- Winter powerhouses: Norway (all-time winter leader), Germany, USA, Austria
