**Author:** Md. Firdous Alam  
**Live Dashboard:** [Tableau Public Profile](https://public.tableau.com/app/profile/md.firdous.alam/viz/GlobalOlympicSportsPerformanceAnalysis_17933559199720/Dashboard3)  

## Overview
Deep-dive analysis into national Olympic performance, detailing the historical dominance of top sporting nations.

## Key Analytical Highlights
- United States (USA): #1 All-time with 2,823 medals (1,131 G, 946 S, 746 B)
- Soviet Union (URS): #2 All-time with 1,204 medals (473 G) across only 18 editions
- Great Britain (GBR): 883 medals; Germany (GER): 798 medals; France (FRA): 840 medals
