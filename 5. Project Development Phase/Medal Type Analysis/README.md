# Medal Type Analysis: Gold, Silver, and Bronze Distribution Patterns

**Project:** Global Olympic Sports Performance Analysis  
**Author:** Md. Firdous Alam  
**Live Dashboard:** [Tableau Public Profile](https://public.tableau.com/app/profile/md.firdous.alam/viz/GlobalOlympicSportsPerformanceAnalysis_17933559199720/Dashboard3)  

## Overview
Comparative breakdown of medal distribution across Gold, Silver, and Bronze tiers, validating weighted scoring models.

## Key Analytical Highlights
- Total verified medals: 18,905 (6,195 Gold, 6,115 Silver, 6,595 Bronze)
- Gold conversion ratio: USA converts 40.1% of all medals to Gold
- Weighted score impact: Elevates high-gold nations (USA, CHN, URS) over bronze-heavy tallies
