# Continent-wise Analysis: Regional Sports Efficiency & Equity

**Project:** Global Olympic Sports Performance Analysis  
**Author:** Md. Firdous Alam  
**Live Dashboard:** [Tableau Public Profile](https://public.tableau.com/app/profile/md.firdous.alam/viz/GlobalOlympicSportsPerformanceAnalysis_17933559199720/Dashboard3)  

## Overview
Continental analysis of Olympic success, highlighting European and American dominance, Asian expansion, and Oceanian per-capita efficiency.

## Key Analytical Highlights
- Europe and Americas account for over 72% of all-time Olympic medals
- Oceania demonstrates the highest per-capita medal yield, driven by Australia and New Zealand
- Africa exhibits supreme efficiency in middle- and long-distance athletics disciplines
