# Host Country Performance: Empirical Validation of the Home Advantage

**Project:** Global Olympic Sports Performance Analysis  
**Author:** Md. Firdous Alam  
**Live Dashboard:** [Tableau Public Profile](https://public.tableau.com/app/profile/md.firdous.alam/viz/GlobalOlympicSportsPerformanceAnalysis_17933559199720/Dashboard3)  

## Overview
Empirical validation of the Olympic host nation advantage across modern Olympic history (1980-2016).

## Key Analytical Highlights
- 86.7% surge rate: 13 out of 15 host nations outperformed their multi-cycle baselines
- Average host bump: +15.4 medals above pre-games baseline
- Peak surges: China +37 (Beijing 2008), Australia +24 (Sydney 2000), Great Britain +18 (London 2012)
