## Overview
Architectural blueprint describing the four core functional layers: Data Ingestion, Engineering & Processing, Analytical Core, and Presentation Interfaces.

## Key Analytical Highlights
- Tier 1: Data Ingestion & Raw Storage
- Tier 2: Data Engineering & Processing Engine (clean_data.py)
- Tier 3: Business Logistics & Analytical Core (analyze.py, exploratory_analysis.py)
- Tier 4: Presentation & Interactive BI Interfaces (Tableau, Flask, 5-Min Video)
