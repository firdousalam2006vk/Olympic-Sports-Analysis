# Dashboard Design: UI/UX Wireframes & Visual Architecture

**Project:** Global Olympic Sports Performance Analysis  
**Author:** Md. Firdous Alam  
**Live Dashboard:** [Tableau Public Profile](https://public.tableau.com/app/profile/md.firdous.alam/viz/GlobalOlympicSportsPerformanceAnalysis_17933559199720/Dashboard3)  

## Overview
User experience architecture, color psychology, and wireframe layout for the two interactive Tableau Public dashboards.

## Key Analytical Highlights
- Dashboard 1: Global Sports Performance Overview (Top 10 Nations, Medal Mix, Centennial Growth)
- Dashboard 2: Regional Efficiency & Gender Dynamics (Continental Yield, Parity Trajectory, Sports Maps)
- Color Palette: Deep Navy (#1B365D), Olympic Gold (#D4AF37), Silver (#94A3B8), Bronze (#B4733C)
- Live URL: Hosted publicly on Tableau Public
