# Problem Statement: Challenges in Olympic Performance & Athletic Conversion

**Project:** Global Olympic Sports Performance Analysis  
**Author:** Md. Firdous Alam  
**Live Dashboard:** [Tableau Public Profile](https://public.tableau.com/app/profile/md.firdous.alam/viz/GlobalOlympicSportsPerformanceAnalysis_17933559199720/Dashboard3)  

## Overview
Detailed articulation of the core challenges, measurement distortions, and analytical gaps that motivate this project.

## Key Analytical Highlights
- Flat medal count distortions ignoring gold medal exclusivity
- Team sport medalist inflation in raw athlete-level records
- Absence of empirical quantification of the Host Nation Advantage
- Lack of unified econometric benchmarks linking funding to medal yield
