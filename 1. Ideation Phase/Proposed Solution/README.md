# Proposed Solution: Multi-Tier Modern Data Analytics Pipeline

**Project:** Global Olympic Sports Performance Analysis  
**Author:** Md. Firdous Alam  
**Live Dashboard:** [Tableau Public Profile](https://public.tableau.com/app/profile/md.firdous.alam/viz/GlobalOlympicSportsPerformanceAnalysis_17933559199720/Dashboard3)  

## Overview
Comprehensive architecture of the end-to-end data pipeline, integrating Python data engineering, Tableau business intelligence, and a web deployment layer.

## Key Analytical Highlights
- Vectorized data cleaning in Pandas with automated schema verification
- Relational medal table creation with composite primary keys [games_id, noc]
- Interactive cloud BI dashboards published to Tableau Public
- Zero-dependency Flask portal serving real-time analytical APIs
