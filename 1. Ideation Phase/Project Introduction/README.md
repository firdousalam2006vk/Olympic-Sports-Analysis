# Project Introduction: Centennial Olympic Performance Analysis

**Project:** Global Olympic Sports Performance Analysis  
**Author:** Md. Firdous Alam  
**Live Dashboard:** [Tableau Public Profile](https://public.tableau.com/app/profile/md.firdous.alam/viz/GlobalOlympicSportsPerformanceAnalysis_17933559199720/Dashboard3)  

## Overview
Introduction to the Global Olympic Sports Performance Analysis project, synthesizing 120 years of historical Olympic competition across 51 editions, 230 National Olympic Committees, and 135,571 athletes.

## Key Analytical Highlights
- Centennial scope: 1896 Athens to 2016 Rio de Janeiro
- 51 total Olympic Games editions (29 Summer Games, 22 Winter Games)
- 18,905 verified Olympic podium medals documented
- Multi-tiered analytical architecture utilizing Python, Pandas, Tableau Public, and Flask
