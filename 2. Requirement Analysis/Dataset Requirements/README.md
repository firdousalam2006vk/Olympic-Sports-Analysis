# Dataset Requirements & Data Governance Standards

**Project:** Global Olympic Sports Performance Analysis  
**Author:** Md. Firdous Alam  
**Live Dashboard:** [Tableau Public Profile](https://public.tableau.com/app/profile/md.firdous.alam/viz/GlobalOlympicSportsPerformanceAnalysis_17933559199720/Dashboard3)  

## Overview
Specification of source data provenance, attribute dictionaries, relational keys, and data cleaning requirements.

## Key Analytical Highlights
- Primary source: Kaggle / TidyTuesday 120 Years of Olympic History
- NOC regional metadata lookup mapping 230 NOC codes to sovereign nations
- Schema normalizations: 18 target athlete attributes, 11 target medal attributes
- Data storage: dual-tier storage (modern era CSV + centennial compressed archive)
