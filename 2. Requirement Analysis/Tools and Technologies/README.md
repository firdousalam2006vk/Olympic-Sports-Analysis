# Tools and Technologies: Architecture & Tool Selection Rationale

**Project:** Global Olympic Sports Performance Analysis  
**Author:** Md. Firdous Alam  
**Live Dashboard:** [Tableau Public Profile](https://public.tableau.com/app/profile/md.firdous.alam/viz/GlobalOlympicSportsPerformanceAnalysis_17933559199720/Dashboard3)  

## Overview
Technical rationale and comparative justification for the selection of Python, Pandas, Tableau Public, Flask, and ReportLab.

## Key Analytical Highlights
- Pandas: Vectorized in-memory ETL for 157k modern athlete rows
- Tableau Public: Industry-standard cloud BI platform for dashboard publication
- Flask: Lightweight WSGI micro-framework for serving analytical APIs
- ReportLab: Programmatic PDF compilation ensuring 100% reproducible documentation
