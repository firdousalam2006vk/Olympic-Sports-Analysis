# Functional Requirements Specification (FRS)

**Project:** Global Olympic Sports Performance Analysis  
**Author:** Md. Firdous Alam  
**Live Dashboard:** [Tableau Public Profile](https://public.tableau.com/app/profile/md.firdous.alam/viz/GlobalOlympicSportsPerformanceAnalysis_17933559199720/Dashboard3)  

## Overview
Detailed specification of functional capabilities required across the ETL pipeline, analytical models, Tableau dashboards, and REST API.

## Key Analytical Highlights
- FR-01 to FR-05: Data ingestion, schema validation, medal deduplication
- FR-06 to FR-10: Weighted scoring, host surge calculation, ROI benchmarking
- FR-11 to FR-15: Tableau interactive filtering, KPI calculation, REST endpoints
